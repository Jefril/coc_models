# 附录E：标记与队列总控（守秘人总表）

## 一、标记（二值）

| 知晓内容 | 后果 |
|------|------|
| 知道「那三年出过事」（年份、死者数、官方死因、习俗） | **安全** |
| 知道「**有什么东西**杀了他们」——知晓「因」、知晓它的存在，只言片语也算 | **标记，入列** |

### 阈值判例（戏内无法确证这条线在哪——守秘人按下表裁定）

| 言语/文本 | 判定 |
|------|------|
| 报纸：「野狗袭人」 | 安全 |
| 酒馆：「那不是野狗干的。有东西——」（海尔加，9/12夜） | **标记**（本模组的标记时刻） |
| 特德的呓语（「别数了」「灯不够」「它不肯上相」） | 安全（只有「事」） |
| 特德的明信片（只谈灯、钟、不睡觉） | 安全 |
| 1905遗信：「那不是野狗。有东西在杀知道它的人。把信烧了。」 | **标记**（信了才感染；当疯话烧掉＝安全） |
| 《熄灯祷文》译文（「它以知晓为名册」） | **标记**（译文本身即感染源） |
| 三代遗稿任何一页，读懂「有什么东西在杀人」这层意思 | **标记** |
| 玩家自己推出来「不是兽」（克罗医生、特德·马什的路径） | **标记** |
| 远远看见它走过（看不清、无法确证「因」） | 安全（目击不标记） |
| 弗洛伦斯的梦报（「它走过防波堤，进了惠特洛家门」） | 对已入列者无增量；对圈外听众＝**标记** |
| 「我当没听见」／自欺 | **无效**（信了才感染——戏内无法自欺：你的脑子夜里知道你是不是在装） |

## 二、发狂出列与治愈回列（与CoC7e衔接）

- **永久疯狂＝出列**：标记要求知识被一个**清醒的心智**连贯地持有；疯子的呓语不算「知道」——碎片无法被它认领。触发：SAN归零（CoC7e永久疯狂），或自愿破碎（见附录F规则卡）。出列者不在名册、不须出席仪式、低鸣对他们停止。
- **临时疯狂≠出列**：仍会回列（碎片终将拼回）。
- **治愈＋记忆尚存＝重新入列**（回队尾）。特德难题的全部重量就在这一条。
- **治愈＋记忆尽失＝不回列**（蓝旗雅各型：烧糊了「为什么怕」）。
