## 三、仪式流程卡（大潮夜快速参照）

**前置核对（9月19日晨）**：

- [ ] 名单在册者全部到场（**活着缺席＝仪式必败**——重蹈1905）？核对外call回程表（末班火车/马车/潮转死线21时）
- [ ] 三烛齐备：蜂蜡（牧师）、鲸油（锡德）、泪（追思现场收）？
- [ ] 承接者已定？（未定→好结局线关闭，转「藏灯式」）
- [ ] 译本完整？（题记可跳过不读——那是给译者的，不是给仪式的）

**流程**：申时点名 → 酉初追思与泪烛（危机：忏悔伏击） → 酉正三烛入槽·承接者立誓 → 戌初外人诵祷（危机：分离事件，择一） → **戌末潮转（约21时，死线）** → 结算。

**誓词与引导词**：见《05_第四章_大潮夜》场景三、四（旧版誓词与第五段引导词照用）。

**结算树**：

```
找齐？─否（活着缺席）─→ 补call：潮转前赶回─失败→ 坏结局轨道
  └─是→ 泪成？─否→ 三烛缺一→ 半闭
        └─是→ 承接者立誓？─无人→ 藏灯式→ 半闭
              └─是→ 三烛至晓＋诵祷成功？（忏悔伏击/大失败可中途破坏）
                    ├─ 全成，且赶在潮转前 → 好结局《守灯人》
                    ├─ 任一残缺 → 半闭《无人的灯》（变体按缺项：无人承接/名册有缺）
                    └─ 崩溃或未及潮转 → 路径C → 坏结局《走出门的它》
```

## 四、发狂出列规则卡

- **触发**：①SAN归零（CoC7e永久疯狂，自然出列）；②**自愿破碎**——被标记者主动选择：冲进荒原直面它（大额SAN损失，见附录D目击表，可连看连扣）、药物（过量镇静剂等，医学检定定后果）、自毁式执念（守秘人裁定时长与检定链），直至永久疯狂。
- **结算**：永久疯狂即出列。角色退场——终幕在济贫院（与艾达、特德为伴，每天喂不存在的猫）。**这不是失败，是一个人扛不动时的法定出口。**
- **守秘人纪律**：**全程序不主动提示这条路**。祷文第五段（「破碎的心智，亦为一扇闭上的门」）只对主动问的人轻声提示，只此一次。等玩家自己想明白的那一刻，这个模组才算跑完。
- **残忍的合法解（暗桩，非提示）**：若玩家想出「把活着缺席/拒绝出席的人弄疯，让他出列、不算缺席」——**规则上成立**（已疯者不在名册）。这是谋杀式的仁慈，守秘人不禁止、不背书，让全桌自己消化。
